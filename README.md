# 🕷️ 抖音爆火 MJ 蜘蛛侠彩蛋聊天室

> 还原抖音爆火的「输入 MJ 召唤蜘蛛侠」特效彩蛋网页。极简纯白现代设计，采用本地原版视频切片，带原声与防连抽算法。

---

## ✨ 核心特性

- **🎬 本地视频 3段毫秒级切片**：自动对本地 `spider.mp4` 进行分段播放控制，永不失效。
- **🎲 防连续重复算法**：真随机抽取，严格限制同一特效最多连续出现 2 次。
- **📱 iOS 现代质感**：纯白空白画板，配备弹性消息气泡与毛玻璃输入栏。
- **⚡ 零构建零依赖**：无任何第三方重型库，极速秒开，完美适配各种设备。

---

## 📂 项目文件清单

请确保以下文件存放在同一目录下：

```text

├── spider.mp4        # 你的原版特效视频文件 (命名必须为 spider.mp4)
